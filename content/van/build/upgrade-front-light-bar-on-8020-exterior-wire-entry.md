- **What:** Mount an off-road **LED light bar on the front 8020** (front crossbar) + add a **new weatherproof exterior wire entry** to power it. *(Distinct from P11, the interior overhead bar.)*
- **Mount:** clamp/bracket the light bar to the front 8020 crossbar (match profile, use T-nuts).
- **Wire entry (the ask):** run power to the exterior through a **weatherproof roof cable gland near the front**. same type as the Starlink gland (P4); a **separate** entry positioned near the bar. Seal butyl/Sikaflex. *(If mounted lower/grille-level instead → firewall grommet.)* Coordinate placement with P4/P18 roof work.
- **Electrical. use a relay (light bars pull real current):** **relay + fused harness**. low-current switch in the cab triggers the relay; main power from the battery via an inline fuse. **Most light bars ship with this harness (relay + fuse + switch)**. confirm yours does. Switch trigger ties into P8 wiring; main feed fused at the battery/busbar.
- **Weatherproofing:** heat-shrink/sealed exterior connections; drip loop at the gland.
- **⚠️ Legal:** forward-facing light bars generally **aren't street-legal on public roads** (many states require a cover / on-road lockout). Fine off-road/at camp. wire the switch accordingly.
- **Need to buy:** LED light bar; 8020 mounting brackets/clamps (match profile); light-bar wiring harness (relay + fuse + switch) if not included; **exterior cable entry gland** (roof gland box / or firewall grommet); butyl/Sikaflex; heat-shrink/weatherproof connectors
- **Tools:** drill ✅
- **Measure/decide:** where on the front 8020 + bar size/length; **wire-entry location** (front roof gland vs firewall). coordinate with P4/P18 roof layout; inside wire-run length; confirm 8020 profile; does the bar include a relay harness?
