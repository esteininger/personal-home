- **What:** A foldable/expandable dog bed for the aisle floor spot so she's not on the bare floor. **Key driver:** damp the van's road vibration (she's uncomfortable with the rattle). Stows by **sliding into a detachable sleeve under the bed** (on the Skorva beams) when not in use. Homemade OK.
- **Design. two-layer foam (comfort + isolation):**
  - **Base: closed-cell foam** (EVA/gym-mat type). the isolation layer that kills floor buzz.
  - **Top: memory / high-density foam**. comfort.
  - *(Elevated cot damps vibration best but doesn't fold/stow. foam wins for the sleeve requirement.)*
- **Foldable:** build **tri-fold** (3 hinged foam segments in one cover) → collapses to 1/3 with a handle + strap.
- **Stow. sliding sleeve/envelope under the bed:** a flat **envelope of heavy fabric** (Cordura/marine canvas), open one end; folded bed slides in like a drawer. **Detachable:** webbing straps wrap the two Skorva beams and close with **side-release buckles** (or heavy snaps) → whole sleeve unclips. **Retention flap + buckle/velcro** across the opening so it can't slide out over a bump.
- **Anti-shake (the priority. slack = rattle):**
  1. **Snug**. size the sleeve tight to the folded bed, no room to bounce.
  2. **Taut**. tension it between the beams (cam straps or **shock cord**. absorbs bumps without going loose), a tight hammock not a saggy one.
  3. **Padded contacts**. closed-cell foam / felt where the sleeve meets the beams + bed underside, so residual movement is deadened not rattling.
  - (The bed's own closed-cell base already damps the package. the sleeve just holds it snug + taut + padded.)
- **Cover:** removable **zippered, washable** cover. waterproof marine-vinyl bottom + durable washable top (claw/wash resistant).
- **Need to buy:** closed-cell foam (base), memory/high-density foam (top), washable waterproof cover fabric (or pre-made zip cover); **sleeve:** heavy Cordura/canvas, webbing + side-release buckles/snaps (detachable beam attach), cam straps or shock cord (tension), closed-cell foam/felt (anti-rattle padding), velcro/buckles for fold + flap
- **Tools:** electric carving knife (foam. same as mattress/bench), drill ✅, heavy-duty sewing (or have the sleeve sewn)
- **Measure:** floor spot L × W; **dog size** (curled + stretched); **Skorva beam spacing (c-to-c)** → sleeve width; **under-bed clearance / beam drop** → sleeve depth (don't hang too low); folded bed size → sleeve internal (snug); beam cross-section → wrap-strap size
