## Walmart Shopping List

- Stabilizer (Aisle L3)
- DampRid (A21)
- Dog food
- Clorox (A21)
- Rain-X windshield repair kit (L4)

## Storage

### 🔋 Electrical

- [ ] Disconnect starter battery negative, or hook up solar panel + controller
- [ ] Disconnect house batteries / set charge level
- [ ] Pull fridge fuse (optional, belt-and-suspenders)
- [ ] Turn off DC-DC charger at relay

### 🛢 Engine / Fuel

- [ ] Change oil & filter
- [ ] Fill gas tank completely
- [ ] Add stabilizer, run engine 10 min to circulate
- [ ] Top off coolant, brake fluid, washer fluid

### 🚰 Plumbing / Water

- [ ] Empty fridge, prop door open, baking soda inside
- [ ] Drain fresh tank (32 gal)
- [ ] Run pump to clear lines, open low-point drains
- [ ] Sanitize with bleach solution, drain, flush, dry
- [ ] Turn off pump and water system

### 🚽 Cassette Toilet

- [ ] Empty & rinse at dump station
- [ ] Sanitize with bleach solution, drain dry
- [ ] Leave blade valve cracked open
- [ ] Lube rubber seal with silicone spray

### 🌬 Moisture / Interior

- [ ] Place 2 to 3 DampRid tubs (front, mid, rear)
- [ ] Stand cushions on edge
- [ ] Remove all food (or seal in rodent-proof bins)
- [ ] Sweep / vacuum interior
- [ ] Close vents / windows if outside; crack if covered

### 🐭 Pests

- [ ] Place borax + sugar bait cups (optional)
- [ ] Stuff steel wool in small entry points
- [ ] Remove any trash or crumbs

### 🚙 Tires / Exterior

- [ ] Inflate tires to max PSI
- [ ] Park on wood / plastic pads
- [ ] Chock wheels
- [ ] Wash & wax exterior
- [ ] Install reflective window covers

### 🗝 Final

- [ ] Remove valuables
- [ ] Lock doors
- [ ] Note mileage & storage date
- [ ] Cover windshield
